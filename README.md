# Nuage de points sur Desk

📝 Description

Ce projet explore l'affichage et l'optimisation du rendu de splats 3D (disques) dans Three.js. Deux approches ont été testées :
- Sans shaders : affichage classique de 10 000 disques indépendants en Three.js.
- Avec shaders (GLSL) : utilisation du GPU pour optimiser l'affichage et appliquer une déformation elliptique des splats en fonction de l’angle de vue.
