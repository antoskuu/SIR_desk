File Explorer - Desk

Description

Explorateur de fichiers basé sur Desk, intégré avec desk.FileSystem et desk.Actions. Il permet de naviguer dans les répertoires, ouvrir et gérer les fichiers en fonction des actions définies dans Desk.

Fonctionnalités

Navigation : Chargement dynamique des fichiers et dossiers.

Gestion des fichiers : Ouvrir, renommer, supprimer, créer.

Affichage en grille : Icônes et labels.

Breadcrumb : Navigation rapide.

Pagination : Chargement optimisé.

Tri & affichage des fichiers cachés.

Menu contextuel : Actions personnalisées Desk.

Utilisation

Démarrer l'application avec Desk.

Modifier rootPath si besoin.

Ajouter des handlers dans handleFile() selon les besoins.
